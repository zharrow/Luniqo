# Phase 3 : Personnel & Planning RH

**Priorité**: 🔴 HAUTE
**Statut**: 📅 PLANIFIÉE (0%)
**Estimation**: 14 jours

---

## 🎯 Objectif

Gestion avancée du personnel :
- Qualifications et certifications
- Planning des équipes
- Conformité taux d'encadrement
- Absences et disponibilités
- Rapports réglementaires

## 📊 Scope

### Tables à Créer (9)
1. `staff_qualification` - Diplômes et certifications
2. `staff_document` - Documents personnel
3. `staff_authorization` - Autorisations professionnelles
4. `staff_shift` - Planning équipes
5. `staff_absence` - Absences personnel
6. `staff_availability` - Disponibilités
7. `staff_assignment` - Affectations salles/sections
8. `regulatory_report` - Rapports conformité
9. `ratio_log` - Historique taux d'encadrement

### Services (3)
- `StaffQualificationService`
- `StaffPlanningService`
- `RegulatoryComplianceService`

### Pages
- `/owner/staff/qualifications` - Gestion qualifications
- `/owner/staff/planning` - Planning équipes
- `/owner/staff/absences` - Gestion absences
- `/owner/reports/compliance` - Rapports conformité
